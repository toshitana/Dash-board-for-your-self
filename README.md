# Focus Kanban

集中力維持を支援するためのデスクトップ常駐型カンバンボードアプリケーションです。

## 概要

「今やるべきタスク」を常にデスクトップの片隅に表示しておくことで、作業の脱線を防ぎ、集中力を維持することを目的としたミニアプリケーションです。

## 主な機能

- **シンプルなカンバンボード**: 「ToDo」「Doing（作業中）」「Done（完了）」の3レーン構成。
- **タスク操作**: ドラッグ＆ドロップによるタスク移動、ダブルクリックによる編集、削除機能。
- **データ永続化**: アプリケーションを再起動してもタスクの状態が復元されます。
- **常時手前表示**: 他のウィンドウに隠れることがありません。
- **透明度コントロール**: `Ctrl+Shift+O`のショートカットキーで、ウィンドウの透明度を3段階（100% → 30% → 0%）に切り替え可能。
- **クリックスルー**: 透明度0%の状態では、ウィンドウがマウス操作を透過し、背面のアプリを操作できます。

## 実行方法

### Windows ユーザー向け

1.  **アプリケーションのビルド**
    *   まず、[Node.js](https://nodejs.org/)（npmを含む）をインストールします。
    *   このリポジトリをクローンまたはダウンロードします。
    *   コマンドプロンプトやPowerShellでリポジトリのルートディレクトリに移動し、以下のコマンドを実行して依存関係をインストールします。
        ```bash
        npm install
        ```
    *   次に、以下のコマンドを実行して、Windows向けの実行可能ファイル（`.exe`）をビルドします。
        ```bash
        npm run build
        ```
2.  **実行**
    *   ビルドが完了すると、プロジェクト内に`dist`というフォルダが作成されます。
    *   `dist`フォルダの中にある`Focus Kanban.exe`を実行すると、アプリケーションが起動します。

### 開発者向け

1.  **依存関係のインストール**
    *   リポジトリのルートで以下のコマンドを実行します。
        ```bash
        npm install
        ```
2.  **アプリケーションの起動**
    *   以下のコマンドで、開発モードでアプリケーションを起動します。
        ```bash
        npm start
        ```
